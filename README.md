📌 Project Overview

This repository contains the solutions for the .NET Diploma assignments. It covers refactoring C++ code into OOP C#, working with projects and tables, locking and concurrency research, Windows Forms views and emails, and a multi-phase order processing system.

The projects demonstrate object-oriented programming, SOLID principles, asynchronous programming, data handling, and problem-solving skills.
